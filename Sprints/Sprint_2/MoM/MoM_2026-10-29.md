## Agenda and purpose

Discuss the years an FVS run should cover, the data we need from GIS and Cruiser, and the fields Flex Taper will need afterward.

## Key discussion points

### FVS runs

- The requested schedule is Year Zero, every year for 15 years, then every five years through year 250. We still need to set up and test those years in FVS.
- Run one timber stand at a time. We need to work out how Cruiser plots and trees become one stand input.
- We expect FVS to keep tree numbers, but we need to check a real output database before using them to match results to measured trees.

### GIS and Cruiser data

- Some fields come only from GIS. We need to list the source of each FVS input field.
- A stand can have several tree species, each with its own site index. Keep those values when we have them. For the first test, one Douglas-fir site index is enough.
- Each cruiser gets elevation information. Use **GIS average elevation** for the FVS run. Confirm how this rule fits with the earlier Cruiser-elevation guidance.
- The Cruiser team plans to measure trees at Kamiak Butte as a test. The FVS variant discussed for that area was **Inland Empire**, which uses habitat type for this site input. Confirm the variant and habitat-type code for the test stand.

### Flex Taper fields and data tracking

- Flex Taper needs plot, tree number, species, diameter at breast height (DBH), stump height, crown, total height, total cubic-foot volume, and total board-foot volume. We need to map each field to its source and units.
- Combine Cruiser data, GIS data, and the information prepared before the cruise. Keep fields even when FVS does not use them.
- Run Year Zero first. For later years, keep the link to original tree data such as stump height. We need to check what FVS outputs for each year.

## Decisions and clarifications

- Start with one stand and a Douglas-fir site index if that is enough for the first test.
- Use GIS average elevation for FVS input; confirm the final rule when both GIS and Cruiser have elevation.
- Keep the full data package and tree IDs so Flex Taper can use FVS results with the original measurements.
- Test the requested output years before relying on the tables.
