## Agenda and purpose

## Key discussion points

### Cruiser and GIS data

- Everyone who is already an authorized user should be able to use Flex Cruiser. We need to work out how access will be set up.
- Before a cruise, gather the stand and site data we already have and send it to the cruiser's phone. GIS can provide plot centers and other location data.
- FVS needs some fields, including site index, that Cruiser may not need. We must decide where those fields will be collected and stored.
- The cruiser measures trees in the field and sends the data back to Serviak. Our team then prepares FVS input, runs FVS, and links the output to the original records.
- We need to decide who combines the Cruiser and GIS data and what format they will use. Dr. Schlosser said Jacob is organizing most of the data.

### FVS runs and fields

- We want a Year Zero run based on measured conditions, followed by runs for later years. The year settings still need to be chosen.
- Start with tree records and the fields needed for total cubic-foot volume, including species, diameter at breast height (DBH), and crown height.
- Check the FRASS code, starting with Flex Taper, to learn which input fields and units it needs.
- Bark thickness can vary by species and location. Dr. Schlosser gave Douglas-fir as an example of trees that may need different values.
- We still need the *Essential FVS* PDF referenced in the documents sent by email.

### Keeping records connected

- Keep fields that FVS does not use. FRASS may need them later.
- Each FVS result must be traceable to its original tree record. For example, we need to reconnect a result to its stump height even if FVS does not use that field.
- We need to check which tree and run IDs remain stable in the actual FVS output.

## Decisions and clarifications

- Gather GIS and other site data before the cruise, get measured Cruiser data back on Serviak, and use the combined records for an FVS run.
- Keep the original fields and a way to match FVS results back to them.
- Use the FRASS and Flex Taper code to identify the fields we need to keep and produce.
- The data format, who does each conversion, and the FVS run settings are still open.
